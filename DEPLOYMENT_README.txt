IMPORTANT REPOSITORY FINDINGS
-----------------------------
1. streamlit_app/app.py imports agents.prediction_agent and agents.graphing_agent,
   but those two modules are absent from the public main branch at the time checked.
   The two Python files included here implement the methods called by that UI.
2. The frontend calls GET /get_earnings, but the current orchestrator does not expose
   that route. Add the endpoint snippet below to orchestrator/orchestrator.py.
3. The current voice agent uses SpeechRecognition AudioFile, which handles WAV
   input. The Streamlit UI currently offers MP3 as well. Change the uploader to WAV
   only unless you separately implement MP3-to-WAV conversion.
4. The checked-in code does not import/use Whisper, pyttsx3, sounddevice, comtypes,
   LangChain, or FAISS in the current frontend/backend path. Do not install them
   solely because they appeared in the old requirements file.
5. Keep all project folders (agents, data_ingestion, orchestrator, streamlit_app)
   in the repository. Do not upload only the frontend folder.

BACKEND ROUTE TO ADD
--------------------
Add this to orchestrator/orchestrator.py after the APIAgent instance is created
(or anywhere after `api_agent = APIAgent()`):

@app.get("/get_earnings")
async def get_earnings(symbol: str):
    try:
        earnings_df = api_agent.get_earnings(symbol)
        if earnings_df is None or earnings_df.empty:
            return {"symbol": symbol, "earnings": []}
        records = earnings_df.to_dict(orient="records")
        clean_records = []
        for row in records:
            clean_records.append({
                "Year": int(row["Year"]) if row.get("Year") is not None else None,
                "Earnings": float(row["Earnings"]) if row.get("Earnings") is not None else None,
            })
        return {"symbol": symbol, "earnings": clean_records}
    except Exception as exc:
        logger.exception("Could not retrieve earnings for %s", symbol)
        raise HTTPException(status_code=500, detail=str(exc))

STREAMLIT COMMUNITY CLOUD
-------------------------
Create app:
    Repository: shekhar421/Paisa-Saathi-AI
    Branch: main
    Main file path: streamlit_app/app.py
    Python version: 3.11 (select in Advanced settings)

In Streamlit app Secrets, set:
    API_URL = "https://YOUR-RAILWAY-BACKEND-DOMAIN"

Use the public HTTPS domain generated by Railway. Do not put GEMINI_API_KEY in
Streamlit secrets unless the frontend itself needs it; the current LanguageAgent
runs in the backend.

RAILWAY BACKEND
---------------
Deploy the same repository as a Railway service, using railway.json:
    Start command:
    uvicorn orchestrator.orchestrator:app --host 0.0.0.0 --port $PORT

Railway should install the root requirements.txt. Add this Railway environment
variable:
    GEMINI_API_KEY = your actual Google AI Studio API key

The current LanguageAgent reads GEMINI_API_KEY. The repository's .env.example
mentions GOOGLE_API_KEY, but that name does not match the current code.

After Railway deploys, open:
    https://YOUR-RAILWAY-BACKEND-DOMAIN/
Expected response:
    {"status":"healthy","message":"Finance Assistant API is running"}

Then set the exact HTTPS domain as API_URL in Streamlit secrets and reboot/redeploy
the Streamlit app.
